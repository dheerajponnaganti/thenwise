# Security

Thenwise holds your chats, so we treat security reports first.

## Report a problem

Report it privately through a [security advisory](https://github.com/dheerajponnaganti/thenwise/security/advisories/new). Please do not open a public issue.

Include what you found, the steps to see it, and the versions `thenwise report` prints.

## What counts

- A secret the mask lets through into the store, the vault or a team share.
- Data leaving the machine without the user turning it on.
- A way around team roles, tokens or deletion on the team server.
- A way for a chat, file or team share to run commands on someone's machine.

## Supported versions

Fixes land in the latest release. Update the plugin from `/plugin`, or run `npm install -g thenwise@latest`.
