Tidewater tracks daily habits and monthly budgets. Data lives on the phone first and syncs when a network is available.
The code is TypeScript everywhere. The parts are the [[Mobile App]], the [[Sync Server]], the [[Docs Site]] and the [[Blog]].
[[Lena Ortiz]] leads. [[Sam Achebe]] owns backend and sync, [[Ivo Petrov]] owns mobile, [[Ruth Halvorsen]] owns docs and writing.
The shared engine for [[Offline Mode]] and merging is the [[Sync Engine]].
